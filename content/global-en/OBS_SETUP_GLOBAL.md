# OBS setup — international presentation

## Sources

1. **Overlay (Browser)**  
   - URL: your QuanBar host app `/overlay`  
   - Width/Height:  
     - TikTok portrait: **1080 × 1920**  
     - YouTube landscape: **1920 × 1080**  
   - FPS: 30  
   - Shutdown source when not visible: off  
   - Refresh browser when scene becomes active: on (optional)

2. **Camera / game / VTuber** under or beside overlay as you prefer.  
   Neon Club works best with dark lower-third so dancers read clearly.

3. **MC audio**  
   - Enable MC audio in host panel.  
   - Route TTS / AI MC into OBS via system audio or VB-Cable.  
   - Keep music bed −18 to −24 dB under voice.

## Scene ideas

- **START**: logo + "LIVE IN 3" + overlay preview  
- **LIVE**: camera + overlay  
- **BRB**: "Type 1 while I'm back" still showing overlay floor  
- **END**: follow CTA card

## Color / readability

- Avoid bright white full-screen backgrounds under overlay text.
- If dancers wash out, lower game brightness or add dark gradient bar behind floor.

## Checklist before GO LIVE

- [ ] Profile = Global EN  
- [ ] Mode = Club or Fortune  
- [ ] Auto-demo floor ON for cold start  
- [ ] Overlay URL loads, banner says TYPE 1 / ASK ANYTHING  
- [ ] Pin comment ready  
- [ ] Title + cover from content pack  
- [ ] Mic levels clean; music ducked  
- [ ] Simulator test: type 1, gift 50, see fireworks

## Mobile host (no PC)

If you only have phone TikTok: run overlay on a second cheap laptop/tablet as browser source into capture card, or use a cloud browser source if your stack supports it. Global EN pack still applies for scripts + titles.
