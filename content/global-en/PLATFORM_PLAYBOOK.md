# Platform playbook — TikTok first, YouTube second

## Priority markets

1. SEA English: PH, MY, SG, IN  
2. US evening crowd

## Language

100% English on stream, titles, pin, bio, MC, AI.  
VI profile stays available for local nights — switch profile in host panel.

## TikTok-first growth

- Go live from a phone portrait pipeline or OBS virtual cam into TikTok Live Studio.
- Overlay: browser source 1080×1920 (or 720×1280 if machine is weak).
- Pin comment always = HOW TO PLAY.
- Goal of live #1–5: teach the mechanic, not "go viral."
- Raid/share with similar interactive hosts when appropriate.

### TikTok time suggestions (host local → audience)

- SEA prime: 20:00–23:00 ICT/PHT  
- US evening: 20:00–23:00 ET (compute your local offset)  
- Test one SEA slot + one US slot in week 2.

## YouTube secondary

- Landscape 1920×1080 overlay variant for desktop viewers.
- Super Chat mapped to gift tiers (see Global EN gift note in config).
- Longer Club shows OK (60–90m). Upload Shorts from the same live.
- Stream title can be calmer; put TYPE 1 in first 60 characters.

## Facebook

- Use when your existing graph is there; same overlay.
- Still English for Global pack nights.

## Conversion loop

Live → teach type 1 → clip Short → Short CTA back to next live → pin teaches again.

## What not to do

- Don't run fake bots or buy viewers.
- Don't scrape competitors' chats.
- Don't promise platform algorithm hacks.
