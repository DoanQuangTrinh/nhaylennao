# Chat games (existing commands only)

Commands you can use: `1` / `join`, `0` / `leave`, `dance`, `style`, `skin`, gifts.

No new backend required — host runs the game socially.

## 1) First 10 type 1

- Announce: "First 10 to type 1 get name shoutouts."
- Call each name as they join.
- Optional prize: first gift from those 10 gets double shoutout.
- Reset: ask everyone type 0, then go again.

## 2) Style parade

- "Everyone on floor type style twice."
- Host comments on looks ("Ken went neon, Mia went gold").
- Winner = host pick or chat spam their name.
- Variant: skin only parade.

## 3) Gift goal ladder

Announce a ladder on stream:

1. Spark goal — small pop
2. Confetti goal
3. Fireworks goal
4. Mega goal

Example ladder (adjust to your audience):

- 20 diamonds → spark storm
- 100 → confetti
- 300 → fireworks
- 1000 → mega + group dance call

Say progress every 2–3 minutes.

## 4) Dance battles (host-led)

1. Pick 2–4 dancers already on floor.
2. "When I say go, type dance."
3. 20-second round. Chat votes by typing a name.
4. Winner stays; challenger types 1 if not on floor.

## 5) Join–leave musical chairs

- Host plays 15s hype.
- "Type 0 now!" then "Type 1 to reclaim!"
- Last 3 back on floor get shoutouts.

## 6) Silent floor challenge

- "Nobody type for 10 seconds… OK break — type 1 flood!"
- Good for cold starts; creates a visual wave.

## 7) Fortune lightning round (Fortune mode)

- "One-word questions only: job, crush, move, money."
- Answer fast, rotate names.
- After 5 answers: "Gift if that hit."

## Host tips

- Explain rules in one breath.
- Always restate the command word.
- Never shame non-gifters; invite them to type 1.
