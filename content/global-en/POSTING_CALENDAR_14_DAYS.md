# 14-day posting calendar

Assumes TikTok-first, English-only Neon Club + 2–3 Fortune nights.

Timezone tips: see PLATFORM_PLAYBOOK.md  
Default live length: Club 60m · Fortune 45m

## Daily structure

- 1 live OR 1 heavy content day
- 3 shorts/day (from live or previous live)
- 10+ comment replies

## If you can only do 4 lives/week

Keep: Day 1, 3, 6, 9 patterns. Still post 3 shorts daily from archive.

## Metrics to track (simple)

- Peak viewers
- Joins (type 1 count approx)
- Gifts total
- Follows from live
- Which short got profile visits

Double down on the format that drives joins + follows, not vanity likes only.
