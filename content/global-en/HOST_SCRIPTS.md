# Host scripts — spoken English

Read naturally. Brackets are optional. Pause after every CTA.

"Yo — Neon Club is live. If you're watching later, type 1 and you'll still hit the floor when people roll in. Right now I'm warming the stage. Type 1 if you're here. Even one person packs this place."

"Quick rules: type 1 join, 0 leave, dance to move, gift for fireworks. I'm not waiting — floor is open."

"While we fill up: style parade in a minute. If you're shy, just type 1. No cam needed. You appear on my stream."

## 1–5 viewers

"We got a squad. [Name], welcome — you on the floor? Type dance for me. Everyone else: type 1, don't just lurk."

"Five spots look better with five bodies. Type 1. First gift tonight gets fireworks + TOP shoutout."

"Chat is the controller. I just host. Type 1 if you're new. Type 0 if you need to bounce — no stress."

## 10+ viewers

"Floor is heating. If you're new, pin is up: type 1 to join. Gifts climb the TOP board. We're running a dance battle in two minutes — type 1 now or miss the lineup."

"Shoutout TOP gifts. If you're not on the board yet, smallest gift still pops spark FX. Let's go."

## First 60 seconds (Club) — default open

"Family — Neon Club is LIVE! Type 1 right now and you appear on the dance floor. Free. No download. Type dance to move. Send any gift and we drop fireworks. Let's pack this floor in sixty seconds — type 1!"
